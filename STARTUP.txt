================================================================================
                        G2G Agent 启动文档（命令行版）
================================================================================
项目: G2G Agent (wiki-Agent)
技术栈: Spring Boot 3.5 + JDK 21 + Maven 3.9
端口: 8080
数据库: H2 (文件模式, ./data/h2/kb)
向量库: Milvus (远程, 配置见 .env)
LLM: DashScope (配置见 .env)

================================================================================
一、前置准备（仅首次需要）
================================================================================

1. 确认 JDK 21 已安装在以下路径之一（run.sh 会自动定位）:
   ~/.local/share/jdks/jdk-21*.jdk/Contents/Home

2. 确认 Maven 3.9 已安装在以下路径之一:
   ~/.local/share/maven/apache-maven-*/bin/mvn
   （或系统 PATH 中的 mvn）

3. 配置环境变量（密钥等敏感信息放在 .env 文件中，已被 .gitignore 排除）:

   cp .env.example .env
   vi .env

   .env 中需要填写的内容:
   ┌─────────────────────┬──────────────────────────────────────┐
   │ 变量名               │ 说明                                  │
   ├─────────────────────┼──────────────────────────────────────┤
   │ DASHSCOPE_API_KEY   │ 阿里云百炼 API Key (sk- 开头)         │
   │ MILVUS_HOST         │ Milvus 服务器地址                     │
   │ MILVUS_PORT         │ Milvus 端口 (默认 19530)              │
   │ MILVUS_USERNAME     │ Milvus 用户名 (默认 root)             │
   │ MILVUS_PASSWORD     │ Milvus 密码                           │
   └─────────────────────┴──────────────────────────────────────┘

   注意: .env 不会被 git 提交，可放心填写真实密钥。

================================================================================
二、快速启动（后台运行，关闭终端不影响）
================================================================================

  cd 项目根目录
  ./start.sh

启动后会自动:
  - 加载 .env 中的环境变量
  - 后台启动 Spring Boot (nohup, 关闭终端仍运行)
  - 轮询健康检查，最多等 90 秒
  - 启动成功后输出访问地址

成功输出示例:
  ✅ 启动成功！
     访问地址: http://localhost:8080/
     健康检查: {"status":"UP"}
     查看日志: tail -f logs/app.log

四、停止说明（支持 Kill）
================================================================================

./stop.sh 的停止策略:
  1. 查找占用 8080 端口的进程 PID
  2. 发送 SIGTERM (kill) 信号，等待最多 20 秒优雅关闭
  3. 若超时未退出，发送 SIGKILL (kill -9) 强制终止
  4. 确认端口释放后报告停止成功

如果 stop.sh 失效，可手动执行:
  lsof -ti:8080 | xargs kill -9

五、验证启动是否成功
================================================================================

方式 1 - 状态脚本:
  ./status.sh
  预期输出:
    进程:   ✅ 运行中 (PID: xxxx)
    健康:   {"status":"UP"}

方式 2 - 健康检查接口:
  curl http://localhost:8080/actuator/health
  预期输出: {"status":"UP"}

方式 3 - 浏览器访问:
  打开 http://localhost:8080/

方式 4 - 对话接口测试:
  curl -X POST http://localhost:8080/api/chat \
    -H "Content-Type: application/json" \
    -d '{"question":"你好","sessionId":"test"}'
  预期: 返回 SSE 流，包含 LLM 生成的回复内容

六、常见问题
================================================================================

Q1: 启动时提示 "未找到 .env 文件"
A1: 执行 cp .env.example .env 并填写真实配置后重试

Q2: 启动时提示 "端口 8080 已被占用"
A2: 应用已在运行，直接访问即可；如需重启先执行 ./stop.sh

Q3: DashScope API Key 为空 / NoOpChatModel
A3: .env 中 DASHSCOPE_API_KEY 未正确填写，检查后 ./restart.sh

Q4: Milvus 连接失败
A4: 检查 .env 中 MILVUS_HOST/PORT/USERNAME/PASSWORD 是否正确，
    确认网络可达后 ./restart.sh

Q5: 启动超时（90 秒）
A5: 查看日志定位原因: tail -f logs/app.log
    常见原因: Maven 下载依赖慢、Milvus 连接超时、JVM 内存不足

Q6: 关闭终端后进程是否还在？
A6: 是的。start.sh 使用 nohup + disown 启动，关闭终端不影响进程。
    可通过 ./status.sh 或 curl 健康检查确认进程仍在运行。

七、文件说明
================================================================================

  run.sh      - 核心启动脚本（定位 JDK/Maven、加载 .env、执行 spring-boot:run）
  start.sh    - 后台启动封装（nohup + 健康检查轮询）
  stop.sh     - 停止脚本（优雅 kill → 强制 kill -9）
  restart.sh  - 重启脚本（stop + start）
  status.sh   - 状态检查脚本（进程 + 健康）
  .env        - 环境变量（密钥等，不入库）
  .env.example - 环境变量模板
  logs/app.log - 应用运行日志（自动创建）
