# WikiAgent 企业知识库 — 本地部署与启动指南

前后端一体运行在同一个 Spring Boot 进程中：后端提供 REST/SSE 接口，前端为内置静态页面（`src/main/resources/static`），浏览器访问 `http://localhost:8080` 即可，**无需单独启动前端服务**。

## 一、前置条件

| 依赖 | 要求 | 说明 |
|---|---|---|
| JDK | 21+ | 本机已安装在 `~/.local/share/jdks/jdk-21.0.2.jdk`（run.sh 自动定位） |
| Maven | 3.9+ | 本机已安装在 `~/.local/share/maven/apache-maven-3.9.16`（run.sh 自动定位） |
| DashScope API Key | 必填 | 阿里云百炼控制台获取（sk- 开头），用于 qwen-plus 对话与 text-embedding-v4 向量化 |
| Milvus | ≥ 2.5，必填 | 远程实例即可；BM25 全文检索依赖 2.5+ 服务端 |

### 1. 配置 DashScope API Key（持久生效）

在 `~/.zshrc`（macOS 默认 shell）中追加，**机器重启后依然生效**：

```bash
cat >> ~/.zshrc <<'EOF'
export DASHSCOPE_API_KEY=sk-替换为你的真实Key
EOF
source ~/.zshrc
```

验证：`echo ${DASHSCOPE_API_KEY:0:6}` 应输出 `sk-` 开头。

### 2. 配置远程 Milvus 连接（持久生效）

```bash
cat >> ~/.zshrc <<'EOF'
export MILVUS_HOST=你的Milvus地址
export MILVUS_PORT=19530
export MILVUS_USERNAME=root
export MILVUS_PASSWORD=你的密码
EOF
source ~/.zshrc
```

> 默认拼接为 `http://$MILVUS_HOST:$MILVUS_PORT`。若你的 Milvus 未开启认证，用户名/密码留任意值即可。

## 二、启动后端

```bash
cd "/Users/huangyuan/Desktop/AI学习/wiki-Agent"
./run.sh
```

run.sh 自动完成：定位 JDK 21 与 Maven 3.9（不依赖系统自带 JDK 8 / Maven 3.6）→ 加载 shell 环境变量 → `mvn spring-boot:run`。

手动方式（等价）：

```bash
export JAVA_HOME="$HOME/.local/share/jdks/jdk-21.0.2.jdk/Contents/Home"
~/.local/share/maven/apache-maven-3.9.16/bin/mvn spring-boot:run
```

看到 `Started WikiAgentApplication` 即启动完成（首次启动约 15-20 秒）。

### 启动验证

```bash
curl http://localhost:8080/api/health
```

期望返回（如实反映各依赖状态）：

```json
{
  "status": "UP",
  "dashscope": {"apiKeyConfigured": true, "chatModel": "qwen-plus", "embeddingModel": "text-embedding-v4"},
  "milvus": {"status": "UP", "version": "v2.5.x"}
}
```

- `milvus.status: "DOWN"` → 检查 MILVUS_HOST/端口/认证，或版本是否 ≥ 2.5（探测超时 3 秒）
- `apiKeyConfigured: false` → `~/.zshrc` 未配置或未 source

## 三、使用前端

浏览器打开 **http://localhost:8080**

1. **知识库管理**标签页：点击"上传并解析"选择文档（支持 TXT / Markdown / PDF / Word docx / Excel xlsx，单文件 ≤ 50MB；旧版二进制 .doc/.xls 不支持，请先另存为新格式）。入库流水线为：解析 → 清洗 → 父子切分 → 向量化 → 写入 Milvus，状态列实时轮询（PARSING…READY / FAILED）。
2. **对话**标签页：输入提问，页面依次展示"查询改写 → 混合检索（BM25+向量 RRF 融合）→ 生成回答"，回答下方显示引用来源（[n] 文件名 · 相关性得分），支持流式输出与"停止"按钮。
3. 顶部徽标实时显示 DashScope Key 与 Milvus 连接健康状态。

## 四、停止与重启

- 停止：在 run.sh 终端按 `Ctrl+C`
- 重启：再次执行 `./run.sh`（H2 数据库与上传文件保存在 `data/` 目录，重启不丢失；但**已入库向量仍需 Milvus 在线才能检索**）

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 端口 8080 被占用 | `lsof -ti :8080 | xargs kill` 后重启 |
| `/api/health` 中 milvus DOWN | 连接被拒/超时：核对 host、端口、认证；确认服务端版本 ≥ 2.5（BM25 Function 必需） |
| 环境变量未生效 | 新开终端会自动加载 `~/.zshrc`；当前终端执行 `source ~/.zshrc` |
| 上传后状态 FAILED | 查看列表中的错误信息；常见为文档内容为空（如纯图片 PDF）或格式不支持 |
| 对话返回"知识库中未检索到相关内容" | 知识库确实没有相关文档，先上传资料（系统如实回答，不编造） |
